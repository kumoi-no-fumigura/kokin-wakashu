## 作品について

最初の勅撰和歌集。20巻・約1,100首。春夏秋冬・賀・離別・羇旅・恋・哀傷・雑などの部立と、仮名序・真名序をもつ。以後の勅撰集の規範となった。

## 底本

- [国歌大観 歌集部](https://dl.ndl.go.jp/pid/873348)（松下大三郎・渡辺文雄 編・国歌大観・1901年・p4-15）

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館の全文テキスト（OCR）から作品の範囲を切り出し、プログラムで歌ごと（詞書・作者・左注を分けて）に段落に分け、ページの先頭や末尾にある書名（柱）を除きました。それ以外は手を加えていません。旧字の誤認識・ルビ・割注などがそのまま混じっています。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 首で、`段落ID<TAB>国歌大観の番号<TAB>詞書<TAB>作者<TAB>歌<TAB>左注` の形です。50段落ごとにファイルを分けています（23ファイル）。 |
| `uta.tsv` | 作中歌の一覧（番号・段落ID・本文・読み・詠み手・種別・原本のコマ）。 |
| `kt-kokin.json` | 本文・底本・作品の説明・作中歌のデータをまとめた JSON（訳は入れず、`yaku/` だけに置いています）。段落ごとに原本のコマ番号があります。 |

段落ID（例: `kt-kokin-kanajo`）は、本文を直しても変わりません。原本の画像は、底本のリンクからコマ番号で見られます。

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/kumoi-no-fumigura/kokin-wakashu/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。
- **直接直す**：`honbun/` の該当行を直して Pull Request を送ってください。段落IDと行の順番は変えないでください。

受け取った修正は、原本の画像と照らして確かめてから取り込みます。
